## 🌐 Práctica 1 — Página de Inicio

### Descripción
Página web de presentación personal desarrollada con HTML5, CSS3 y JavaScript puro.
Incluye las siguientes secciones:

- **Inicio (Hero):** Presentación con animaciones y llamado a la acción.
- **Sobre mí:** Información personal y datos de la asignatura.
- **Habilidades:** Barras de progreso animadas mostrando competencias técnicas.
- **Contacto:** Formulario interactivo con validación y mensaje de confirmación.

Aplica conceptos de usabilidad, diseño responsivo, jerarquía visual y accesibilidad.

### Cómo ejecutarlo
1. Abre la carpeta `pagina-inicio/`.
2. Haz doble clic en `index.html`.
3. Se abrirá directamente en tu navegador web (no requiere servidor ni instalación).

## 🎮 Práctica 2 — Juego: Tres en Raya

### Descripción
Juego clásico de Tres en Raya (Tic-Tac-Toe) para dos jugadores, desarrollado con HTML5, CSS3 y JavaScript.

**Características:**
- Tablero interactivo 3×3 con animaciones de entrada.
- Indicador de turno en tiempo real (Jugador ❌ vs Jugador ⭕).
- Detección automática de ganador y empate, con resaltado de la combinación ganadora.
- Marcador persistente de victorias y empates durante la sesión.
- Modal de resultado con animación al finalizar cada partida.
- Botones para iniciar nueva partida y reiniciar el marcador completo.
- Diseño responsivo adaptable a pantallas pequeñas.

### Cómo ejecutarlo
1. Abre la carpeta `juego/`.
2. Haz doble clic en `index.html`.
3. Se abrirá directamente en tu navegador web (no requiere servidor ni instalación).
4. Juegan dos personas en el mismo dispositivo, turnándose en el teclado/ratón.
